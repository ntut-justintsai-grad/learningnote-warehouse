資料庫 · SQL GROUP BY

SQL 分組與彙總

把多筆明細依欄位分組，算出每組的筆數與合計。

核心觀念

GROUP BY 將相同分類的資料列放進一組，再由 COUNT、SUM 或 AVG 計算組內的彙總值。查詢會為每個分組留下對應的彙總結果。

操作範例

Sales 範例資料
categoryamount
文具120
食品80
文具50

步驟 1 / 3

讀取三筆交易

明細依序是文具 120、食品 80、文具 50。每一列代表一筆交易。

把相同分類放在一起

GROUP BY category 形成兩組：文具含 120、50，食品只有 80。

在每一組內計算

文具的 COUNT(*) 是 2、SUM(amount) 是 170；食品的筆數是 1、合計是 80。

SELECT category, COUNT(*) AS row_count, SUM(amount) AS total_amount
FROM Sales
GROUP BY category;
查詢結果（列順序可變）
categoryrow_counttotal_amount
文具2170
食品180

使用時機

適用於依商品類別彙總銷售額、依班級計算人數等情境。要在分組前篩選明細用 WHERE，要篩選分組結果用 HAVING。

理解小測驗

1. 文具組的 COUNT(*) 與 SUM(amount) 是多少？

文具共有 120 和 50 兩筆，因此筆數為 2，合計為 170。

2. 想找合計超過 100 的分類，應用哪個子句？

HAVING 可以用 SUM(amount) 篩選分組之後的結果。
