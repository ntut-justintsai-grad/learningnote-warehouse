作業研究 · Earliest Due Date · EDD

最早到期日法則

依到期日排隊，找出能讓最大延遲最小的順序。

核心觀念

在單機、工件同時可加工且不可中斷的假設下，EDD 可最小化最大延遲。工件延遲為完工時間減到期日，負值代表提早完成。

操作步驟

  1. 依到期日從早到晚排列工件。
  2. 從時間 0 起累加加工時間，得到各工件的完工時間。
  3. 以完工時間減到期日，取其中最大值。

手算例題

工件資料
工件加工時間到期日
A44
B35
C26
D18

步驟 1 / 3

先找出最早到期的工件

四個到期日是 4、5、6、8，因此依 A、B、C、D 排列。

累加加工時間

A 完工於 4，B 再加 3 得到 7，C 再加 2 得到 9，D 再加 1 得到 10。

找出最大的延遲

完工時間逐一減去到期日，得到 0、2、3、2。最大延遲為 3，出現在 C。

順序 A → B → C → D。完工時間依序為 4、7、9、10，延遲為 0、2、3、2，最大延遲為 3。B、C、D 共三件逾期。

適用情境

當你關心最晚的工件會超出交期多久，可先用 EDD。若績效指標是逾期件數，則可使用 Moore–Hodgson。

理解小測驗

1. 哪件工件的延遲最大？

C 在時間 9 完工，到期日是 6，因此延遲 3。

2. EDD 在本例假設下最小化什麼？

EDD 最小化最大延遲。若目標是最少逾期件數，可用 Moore–Hodgson。
