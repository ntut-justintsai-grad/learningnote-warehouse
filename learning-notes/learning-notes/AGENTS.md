# 學習筆記庫 · AI 開發指南

## 專案目的

建立可持續新增內容的繁體中文筆記網站，支援不同課程、工具與研究方法。每篇筆記聚焦一個讀者能複述或實作的概念。

## 檔案與建置

| 路徑 | 用途 |
| --- | --- |
| `notes/<slug>.json` | 一篇筆記的原始內容 |
| `build.mjs` | 依分類產生首頁與文章頁 |
| `interactive.js` | 逐步例題與測驗的共用行為 |
| `styles.css` | 所有頁面共用的樣式 |
| `docs/` | GitHub Pages 發布目錄，由建置程式產生 |

執行 `node build.mjs` 產生網站。提交筆記來源時一併提交重建後的 `docs/`。樣式或版型調整集中在來源檔，產生的 HTML 由建置程式更新。

## 筆記格式

- 檔名用英文小寫 kebab-case，例如 `sql-group-by.json`。名稱成為頁面網址，既有檔名在編輯時應保留。
- 每篇必填 `title`、`subtitle`（英文名稱或簡稱）、`category`（繁中分類）、`summary`、`sections`。
- `sections` 依閱讀順序排列。每節有 `heading`，並以 `blocks` 放入內容區塊。
- 可用區塊為 `paragraph` 或 `callout`（都用 `text`）、`list`（用 `items`，可加 `ordered: true`）、`table`（用 `caption`、`headers`、`rows`）、`code`（用 `text`）。
- 先說核心觀念，再提供步驟、例題、指令或比較，最後補上用途或容易混淆的地方。按主題選擇合適區塊，並驗算數字與查核指令的輸出。

## 新增內容的流程

1. 閱讀最接近的既有筆記。計算例題參考 `notes/edd.json`，指令教學參考 `notes/sql-group-by.json`。
2. 新增一個 JSON 檔。要新增分類，只需設定新的 `category`，首頁會自動分組。
3. 執行 `node build.mjs`，確認首頁列出新筆記，文章可以開啟並返回索引。
4. 檢查窄螢幕上的標題、表格和程式碼可讀性。若改了共用版型，也要確認既有文章正常。

## 介面規則

維持米白底、深藍字、橘色重點與襯線標題。共用版型使用語意化 HTML、鍵盤焦點及相對連結，以支援本機與 GitHub Pages 子路徑。保持零 npm 依賴，例題使用自建資料，公開內容避免包含個資與憑證。

## 互動例題與測驗

- 逐步例題區塊使用 `{"kind":"stepper","steps":[{"title":"步驟標題","text":"本步要做什麼，以及為什麼"}]}`。放入至少兩個步驟，每步只解釋一個動作，再用下一步呈現推導或結果。
- 單選測驗區塊使用 `{"kind":"quiz","questions":[{"prompt":"題目","options":["選項一","選項二"],"answer":0,"explanation":"判斷理由"}]}`。每題至少兩個選項，且只有一個正確答案。`answer` 從 0 開始計算。解說要能指出依據或展示算式。
- 同一篇可有多個互動模組。新增筆記時在 JSON 選用區塊，網站共用 `interactive.js` 處理換步、計分、回饋與重做。
- 互動例題放在核心觀念之後。安排測驗時，練習題應能用本篇已教過的內容解答。
- 重建後驗證首末步按鈕狀態、作答回饋、分數與重做。互動元件需可鍵盤操作，答案判斷須能以文字辨識。
