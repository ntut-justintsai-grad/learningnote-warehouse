資料庫 · SQL GROUP BY

SQL 分組與彙總

把多筆明細依欄位分組，算出每組的筆數與合計。

核心觀念

GROUP BY 將相同分類的資料列放進一組，再由 COUNT、SUM 或 AVG 計算組內的彙總值。查詢會為每個分組留下對應的彙總結果。

操作範例

Sales 範例資料
categoryamount
文具120
食品80
文具50
SELECT category, COUNT(*) AS row_count, SUM(amount) AS total_amount
FROM Sales
GROUP BY category;
查詢結果（列順序可變）
categoryrow_counttotal_amount
文具2170
食品180

使用時機

適用於依商品類別彙總銷售額、依班級計算人數等情境。要在分組前篩選明細用 WHERE，要篩選分組結果用 HAVING。
